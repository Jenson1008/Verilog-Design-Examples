# seqmult 行为简介

`seqmult` 接收两个 8 位输入 `in_a`、`in_b`，并输出 16 位乘积 `out_prod` 和标志 `out_valid`。在 `clk` 上升沿且 `load` 为高时，模块先把此前保存的八组部分积相加并写入 `out_prod`，同时将 `out_valid` 置高；随后才依据当前输入生成新的八组部分积。每组对应 `in_a` 的一个位：该位为 1 时保存 `in_b` 左移相应位数的值，否则保存 0。因此一个 load 沿的输出由先前保存的部分积决定，而不是该沿刚采样输入所产生的部分积。

`out_valid` 在 load 操作后保持为高，直到复位。`reset` 上升沿也会触发过程；当其为高时，`out_valid` 清零且 `out_prod` 写入 16 位 Z，部分积数组不复位。由于部分积没有初始化，第一次 load 时输出所累加的旧值尚未定义；之后的 load 才会使用此前已保存的输入部分积。
