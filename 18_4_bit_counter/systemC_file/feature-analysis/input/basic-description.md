# counter4bit

## 设计行为

`counter4bit` 由两个在 `clk` 上升沿运行的时序过程组成。第一个过程在高电平 `reset` 的有效上升事件时异步把 `count_out` 设为 `S0=8`；未复位时，它在时钟沿把先前的 `count` 装入 `count_out`。第二个过程根据当前 `count_out` 和控制输入计算 `count`：`load` 与 `enable` 同为高时，`count` 沿默认的 14 个状态值 `8, 7, 11, 4, 9, 2, 5, 12, 6, 3, 15, 1, 14, 13` 循环；在该过程采样到 `load=0` 时，`count` 设为 8。两个寄存器在同一时钟沿各自依据更新前的值工作。

`count_out` 和 `count` 都是顶层可见的四位输出。`count` 没有复位或初始赋值，所以复位本身不确定它的值。另有一个必须保持未决的边界：若 `reset=1`、`load=1`、`enable=0` 与 `clk` 上升沿同时出现，两个 RTL 过程都可能写 `count_out`，源码没有定义其优先级；本描述不推断该碰撞下的最终值。
