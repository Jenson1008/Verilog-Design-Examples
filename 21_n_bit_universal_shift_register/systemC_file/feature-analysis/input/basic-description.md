# univ_shift 行为简介

`univ_shift` 是一个 16 位移位寄存器，输入数据由 `data_in` 提供，`control` 选择输出寄存器的更新方式。`clk` 上升沿触发状态过程：控制值 `00` 保持原有 `data_out`，`01` 将 `data_in` 左移一位，`10` 将其右移一位，`11` 将 `data_in` 直接装入 `data_out`。移位和直通路径都取自当前 `data_in`，不是对旧 `data_out` 连续移位。

`reset` 为高时，过程触发后把 `data_out` 清零。实现除时钟上升沿外也对 `reset` 下降沿敏感；由于清零条件仍是 `reset` 为高，下降沿变低后会按当前 `control` 执行一次相应数据路径，或在保持模式下保持输出。这保留了 RTL 中敏感事件与条件极性不一致的行为。
