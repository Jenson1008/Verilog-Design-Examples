# alu

## 设计行为

`alu` 接收两个四位操作数 `a`、`b`，根据两位 `select` 选择源码定义的加、减、乘或除，并把四位结果送到 `out`。`carry` 反映内部五位运算结果的第 4 位；`zero` 表示当前保存的四位结果是否为零，`sign` 取该结果的最高位，`parity` 表示结果的偶校验值。`overflow` 按源码中的操作数符号位与结果符号位关系计算。除数为零时，SystemC 将结果和 `carry` 置为 X。

重要的实际行为是：RTL 的 `always @(a or b)` 和 SystemC 的敏感列表都没有包含 `select`。因此仅改变 `select` 不会触发运算，`out`、`carry` 及标志保持此前的输出；只有 `a` 或 `b` 变化后，过程才会读取当时的 `select` 并尝试执行相应操作。
