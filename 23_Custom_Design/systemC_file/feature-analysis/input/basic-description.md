# custdesign 行为简介

`custdesign` 顶层接收 `x`、`clk` 和 `reset`，输出 `y`。内部由两个共用时钟的 SRFF 级联构成：第一级的状态为 `a`，第二级的状态为 `b`。组合逻辑根据当前 `a` 与 `x` 形成中间反馈量；该量及其反相信号送入两个 SRFF 的控制端，同时它与当前 `b` 异或后形成 `y`。因此 `y` 会随 `x` 或内部状态改变而重新计算，而状态只在时钟沿更新。

在 `clk` 上升沿，每个 SRFF 根据当时的控制输入更新 `q`；`reset` 为高时该级的 `q` 清零，否则按 SRFF 的输入关系更新。`qbar` 在每个时钟沿另行写入该沿之前旧 `q` 的反相，即使复位清零时也如此，所以它可能与刚更新后的 `q` 不互补。两个 SRFF 状态均没有初始化值，初次复位前的状态和相关组合输出不确定。
