# asyncfifo 行为简介

`asyncfifo` 是一个受限范围的双时钟 FIFO 原型，写入过程由 `write_clk` 上升沿触发，读取过程由 `read_clk` 上升沿触发。被接受的写操作在写指针位置存入 `data_in` 并推进写指针；被接受的读操作将读指针位置的数据送到 `out` 并推进读指针。共享占用计数决定 `mem_full`（计数为 8）和 `mem_empty`（计数为 0）；`count` 对两个时钟上升沿都敏感，写使能单独有效时加一、读使能单独有效时减一，两者同值时保持。低有效复位下降沿清零读写指针和 count，不清除存储器或 `out`。

该原型保留了公开 RTL 的结构限制：两个时钟域均可能写 `out`。若同一仿真时刻的两个上升沿都对应被接受的读写操作，RTL 对 `out` 存在竞争赋值，当前实现将该碰撞结果抽象为 X；这不表示已确定某种 Verilog 调度结果，也不构成无条件等价承诺。单独的有效写操作会使 `out` 写为 Z，单独的有效读操作会使 `out` 写为读出字节。

共享计数器以及读写指针没有 CDC 同步机制，因此该模型不代表安全的跨时钟域 FIFO。满/空违规访问、碰撞情形和异步指针稳定性均未验证；这些范围不能从本原型的顺序读写行为推出确定结论。
