# asyncfifo SystemC 转换状态

此包目前是**受限范围的原型，不是无条件完成或可交接的转换**。RTL 的写时钟进程会在成功写入时对 `out` 赋 `Z`，读时钟进程则在成功读取时对同一寄存输出赋读数据；两种操作在同一仿真时刻有效时，RTL 对该寄存器存在进程竞争。本原型将该碰撞抽象为 `X`，这不是对某个 Verilog 调度顺序的等价承诺。自检只覆盖分开的有效写/读沿、空/满转换和顺序读回，未覆盖并发有效访问、时钟同刻碰撞或完整 CDC 行为。

在用户/协调阶段明确碰撞路径的允许语义之前，应将本设计视为阻塞；不得将本包的有限仿真描述成周期精确等价或形式证明。RTL 本身也没有 CDC 同步器，模型仅照其公开计数/指针行为建模。
