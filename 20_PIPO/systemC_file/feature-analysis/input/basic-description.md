# pipo_shift

## 设计行为

`pipo_shift` 在 `clk` 上升沿处理 16 位并行数据。高电平 `reset` 是同步复位，只把 `data_out` 清零；内部 `temp_data` 不被清除。未复位且 `load` 为 1 时，RTL 在同一时钟事件中把当前 `data_in` 写入 `temp_data`，并根据非阻塞赋值语义用更新前的 `temp_data` 计算 `data_out`，所以装入的新字要到后续一次有效装载操作才会成为移位操作的源数据。`shift_en` 的 00/01/10/11 分别选择左移、逻辑右移、对无符号向量执行的左移，以及显式保留最高位的右移；00 与 10 在当前无符号实现中的位移结果相同。`load` 为 0 时输出保持，复位也不会清除内部暂存字。两个寄存器均未在 RTL 中声明初值。
