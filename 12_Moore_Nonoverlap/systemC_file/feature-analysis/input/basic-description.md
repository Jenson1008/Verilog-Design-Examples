# moore_nonol

## 设计行为

`moore_nonol` 按串行输入逐步推进状态，以输入序列 `1101` 到达检测状态 `S4`。输入或当前状态变化时，组合译码进程计算待装入的 `next_state`；只有在 `clk` 的有效上升沿，状态寄存器才把该值更新为 `present_state`。因此输入引起的状态转移要到时钟沿才生效，`out` 则由当前状态译码，在状态到达 `S4` 后变为 1。

高电平 `reset` 的异步有效事件不等待时钟沿，直接将 `present_state` 置为 `S0`；状态译码随后把 `out` 更新为 `S0` 对应的值。复位前的状态寄存器没有初始值。RTL 对 `present_state` 的 case 没有 default 分支，所以未列出的状态编码不会更新 `next_state` 和 `out`，二者保持先前值。离开 `S4` 时，输入为 1 会转到 `S1`，输入为 0 会转到 `S0`，这是源码规定的具体转移。
