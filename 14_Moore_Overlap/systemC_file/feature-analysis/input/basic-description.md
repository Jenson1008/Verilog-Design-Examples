# moore_ol

## 设计行为

`moore_ol` 逐位接收串行输入，状态寄存器保存与目标序列 `1101` 前缀相符的进度。`clk` 上升沿把组合计算的下一状态写入当前状态；高电平 `reset` 上升沿异步把状态送回 `S0`。输出由当前状态译码：状态 `S4` 时 `out` 为 1，其余已定义状态为 0；因此输入改变会先影响下一状态，当前输出在状态实际更新后才随状态译码变化。完成匹配后，后续输入为 1 时从 `S4` 转到 `S2`，保留前缀 `11`；输入为 0 时转到 `S0`。状态寄存器没有声明初值，RTL 的非法状态 `default` 分支只设置下一状态而不更新输出。
