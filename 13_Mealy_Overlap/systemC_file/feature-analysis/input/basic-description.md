# mealy_ol

## 设计行为

`mealy_ol` 是逐位工作的串行序列状态机，状态记录输入流中与 `1101` 前缀相符的部分。`clk` 上升沿推进状态；高电平 `reset` 上升沿异步返回 `S0`。状态译码进程同时观察当前状态和 `in`，因此 `out` 是组合结果：在状态 `S3`（已匹配前缀 `110`）且当前输入为 1 时拉高，在其余已定义状态中为 0。匹配后若当前输入为 1，下一状态为 `S1`，保留可继续参与后续匹配的后缀；若当前输入为 0，则回到 `S0`。复位前状态未初始化，不能假定输出初值。RTL 对非法状态没有 `default` 分支，相关组合量会保持先前赋值；复位后的有限自检未覆盖任意非法编码。
