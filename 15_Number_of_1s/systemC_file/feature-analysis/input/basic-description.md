# no_1s

## 设计行为

`no_1s` 用一个 16 位输入向量和内部整数索引逐拍累加其中的 1。索引 `i` 在 RTL 中初始化为 0；每个 `clk` 上升沿读取 `i_a[i]`，当 `i<16` 且未复位时，把该位的值加到 4 位输出 `no_ones`，然后索引递增。因此扫描顺序从位 0（最低位）到位 15，每个有效周期只处理一位。高电平 `reset` 是同步复位：在被采样的上升沿把 `no_ones` 清零，但同一进程仍递增 `i`，并不重新开始扫描。索引达到 16 后，非复位周期不再改写输出；之后的 reset 仍会清零输出，但索引继续前进，所以不会自动重扫输入。输出寄存器本身没有初始化值，首次写入前不能假设其内容。
