# mealy_nonol

## 设计行为

`mealy_nonol` 按时钟逐位接收串行输入，内部状态记录与目标序列 `1101` 相符的前缀。状态寄存器在 `clk` 上升沿更新；高电平 `reset` 的上升沿可不等待时钟而把状态异步送回 `S0`。另一组合进程对状态和 `in` 的变化作出响应：在尚未完成匹配的状态中，输出为 0；当状态已对应前三位 `110` 且当前 `in` 为 1 时，`out` 组合地产生 1。该次输出不等待后续时钟沿，状态在下一次状态更新时从 `S3` 返回 `S0`，因此匹配后不保留重叠前缀。源码没有为状态寄存器声明初始值；复位前状态及其译码输出不能据此预设为确定值。RTL 的 `default` 分支给 `next_state` 赋回 `S0`，但不赋 `out`。
