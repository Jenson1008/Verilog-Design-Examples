# dualport_ram 行为简介

`dualport_ram` 提供两个共用 `clk` 的访问端口，内部存有 8 个 128 位字。每个时钟上升沿，端口 A 和端口 B 各自依据本端口的 `wr_en` 与地址独立操作：写使能为高时，将本端口的输入数据写入所选字；否则把该沿采样地址所指的存储内容送入本端口的 `data_out`。处于写模式的端口不更新自己的输出寄存器，因此输出保持此前值。两端口在不同地址同时写入时，分别更新各自选中的字。

读操作在同一时钟沿采样写入提交前的 RAM 内容；因此一端口读取另一个端口正在写入的同一地址时，读取到的是该沿之前存储的内容。若两个端口同沿同时写同一地址，RTL 会对同一个字安排相互竞争的非阻塞写入，没有可移植的端口优先级。当前受限转换不推断 A/B 胜出者，只把发生冲突的那个存储字标为 X；端口输出仍按各自写模式保持。该同址双写情形未被自检激励，后续读取该字的行为仍属 unknown。

设计没有复位端口，RAM 与两个输出寄存器均未初始化；在相关地址写入之前，读出的内容不能视为已知。
