# 64 位流水乘法器

`pipeline` 接收 64 位输入 `x` 和 `y`，并通过输出 `prod` 给出 128 位乘积。每个时钟上升沿，输入被采样并进入乘法流水级；内部将操作数分成高、低 32 位形成部分积，再经后续流水级合并为完整结果。该接口没有 `ready` 或 `valid` 信号。

`reset` 是同步高有效复位，只在时钟上升沿清零输入寄存器 `xtemp` 和 `ytemp`；它不会在该沿清除其他流水寄存器，因此输出不会因复位断言而立即整体清零。输入保持稳定时，从首次在上升沿采样起，经过 5 个上升沿后，`prod` 收敛为这两个 64 位输入的乘积。若 `x`、`y` 连续逐拍变化，`prod` 由不同流水级的寄存器片段拼接而成，输出的各段可能来自不同输入采样时刻，不能将每拍的 `prod` 视为同一笔输入乘积。
