# syncfifo 行为简介

`syncfifo` 使用单个 `clk` 管理 8 个 8 位存储字、读写指针和占用计数。`full` 在计数为 8 时有效，`empty` 在计数为 0 时有效。时钟上升沿上，写过程仅在 `write_en` 为高且 `full` 为低时把 `data_in` 写入写指针所指位置并推进写指针；读过程仅在 `read_en` 为高且 `empty` 为低时把读指针所指字送到 `out` 并推进读指针。没有成功读取时，`out` 保持此前值。

低有效 `reset` 的下降沿会异步清零读指针、写指针和占用计数；RAM 与 `out` 不在复位分支中清除。占用计数过程按 `write_en` 与 `read_en` 的组合独立更新：仅写请求时加一，仅读请求时减一，两者相同则保持。因而该计数更新不等同于“成功入队/出队”的数量；对满/空边界之外的访问可能导致计数和指针不一致，相关越界行为不能据此描述为正常 FIFO 契约。
