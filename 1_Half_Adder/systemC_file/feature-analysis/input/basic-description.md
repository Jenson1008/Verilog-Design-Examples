# 半加器设计说明

## 已知设计功能

顶层 RTL 模块 `half_adder` 有两个 1 位输入 `i_a`、`i_b`，以及两个 1 位输出 `o_sum`、`o_carry`。`o_sum` 由输入异或得到，`o_carry` 由输入与得到。RTL 为连续赋值组合逻辑，不包含时钟、复位、状态元素或显式延迟。

## SystemC 建模说明

SystemC DUT 保持模块名和端口名，使用 `sc_logic` 保留单比特 0、1、X、Z 值，并以 `SC_METHOD` 在任一输入变化时更新输出。testbench 与 DUT 分离；独立真值表穷举两个输入在 0、1、X、Z 下的全部 16 种组合。二值期望值由整数加法计算，四态期望值由预先列出的 Verilog 四态真值表给出。每组输入稳定 1 ns 后采样，结果按端口名打印并写入 CSV。

## 未知与限制

RTL 未指定任何时钟、复位或时序状态行为，也未描述超出 Verilog 位运算规则的未知值解释。有限仿真验证不构成形式等价证明。
